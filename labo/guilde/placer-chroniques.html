Caler la carte des Chroniques · d’abord règle les colonnes et les lignes pour que le quadrillage tombe sur les dalles du dessin ; puis choisis un outil et touche les cases. Sol = on marche dessus ; Mur = mur ou vide ; Obstacle = meuble fixe ; Porte ; Meuble = à fouiller ; Départ = 4 cases ; et les objets du scénario (leviers, axe, livre, statues…). Un 2e toucher avec le même outil défait.
