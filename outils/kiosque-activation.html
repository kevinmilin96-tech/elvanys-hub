Activer le blocage total de la borne

Kiosque Elvanys · une seule fois par tablette · environ 10 minutes · un PC Windows et le câble USB de la tablette

Pourquoi un PC ? Android interdit à une application de se verrouiller toute seule. Une seule commande, tapée depuis un PC, déclare Kiosque Elvanys « propriétaire de la tablette ». Ensuite, plus aucune sortie possible (ni par le bas, ni par les applis récentes, ni par les notifications), sauf par le menu responsable et votre code de sortie. Rien n’est effacé sur la tablette. Cochez les étapes au fur et à mesure.

1 Sur la tablette : retirer tous les comptes

Sans ça, Android refuse la commande de l’étape 5. Ensuite, la tablette reste sans compte tant qu’elle sert de borne : elle n’en a pas besoin.

2 Sur la tablette : activer le débogage USB

3 Sur le PC : installer l’outil d’Android

4 Brancher la tablette

.\adb devices
✓ Exemple de bonne réponse : R52T80ABCDE   device

5 La commande qui verrouille

L’application Kiosque Elvanys est déjà installée sur la tablette : il suffit de taper :

.\adb shell dpm set-device-owner fr.elvanys.kiosque/.AdminReceiver
✓ Bonne réponse : elle commence par Success: Device owner set to package…

Si l’application n’était pas installée : copier d’abord le fichier kiosque-elvanys-1.1.apk (boîte à outils du Hub) dans le dossier platform-tools, puis taper .\adb install kiosque-elvanys-1.1.apk.

6 Vérifier

Si la commande répond un message d’erreur

… already some accounts on the deviceIl reste un compte sur la tablette : retour à l’étape 1 (Google, compte de la marque, Dossier sécurisé). Si un compte refuse de partir : remise à zéro de la tablette, sans ajouter de compte Google à l’accueil.
… already several users on the deviceSupprimer les autres utilisateurs (Paramètres → Comptes → Utilisateurs) et le Dossier sécurisé (Samsung).
… device owner is already setUne autre application de gestion est déjà « propriétaire » (ex. une ancienne appli de borne) : la désinstaller, ou remettre la tablette à zéro.
unauthorizedAccepter le message « Autoriser le débogage USB ? » sur la tablette (étape 4), puis retaper la commande.
(aucun appareil dans la liste)Essayer un autre câble (certains ne font que charger) ou un autre port USB ; vérifier le Débogage USB (étape 2) ; tablette Samsung : installer le « Samsung USB Driver » sur le PC.
adb n’est pas reconnu…Le Terminal n’est pas ouvert dans le dossier platform-tools (étape 3), ou il manque .\ devant adb.
Unknown admin / not foundL’application Kiosque Elvanys n’est pas installée : voir la note de l’étape 5.

Un autre message ? Prenez-le en photo et envoyez-le à Claude.

Bon à savoir

  • Réglages de la borne (wifi…) : se connecter au Hub de la borne avec un compte administrateur → « Réglages de la borne », puis le code de sortie. Sans réseau : bouton « Réglages » de l’écran « Pas de réseau ».
  • « Quitter la borne et rendre la tablette normale » (menu responsable) retire le blocage total : il faudra refaire cette fiche pour le remettre.
  • Code de sortie perdu : seule une remise à zéro de la tablette permet d’en sortir.
